# 澄灯 LumaRV 拍摄与配音脚本

成片建议2分30秒至2分45秒。用“接入控制板—临时调参—保持其他状态—读回—拒绝越界”串起镜头。先录完整操作原片，再剪辑；3D动画与等待过场使用3倍速，结果特写恢复正常速度。

## 拍摄准备

把板卡、电源、串口USB和JTAG放在同一画面内，背景不出现姓名、学校或导师信息。关闭其他串口程序，在Edge打开：

http://127.0.0.1:8765/?present=1&baud=921600&arch=1

选择CP210x对应端口、921600波特率。连接成功后短按KEY0，等页面显示“就绪”。这台电脑当前端口为COM10，FTDI的COM13/14用于JTAG。若端口打不开，先退出占用它的页面或串口助手。

拍摄前点“快速控制”，等准备完成，发送`led 0`建立初始状态。拍摄时每次等“就绪”再发下一句。

## 双核并行补拍

点“后台计算自检”，看到副核忙碌后，立即点“一键AI识别·PWM20%”，随后点“快速控制”发送`led 37`。同框拍到副核仍在运行、主核已返回AI结果和LED读回。等副核完成后，再录CPU自检成绩。配音：“长计算交给独立副核，主核继续接收请求和操作外设；两核各用自己的存储，避免后台任务阻塞临时复测。”

## 两条最省事的录制内容

1. **一键AI识别·PWM20%**：按钮自动确认模式并发送中文请求，镜头拍到模型耗时、20%请求及回读。
2. **快速控制后发送`led 37`**：拍到实物LED变化和掩码37。

若时间允许，加拍一次频率越界拒绝和CPU自检。不要连续点击模式按钮；页面确认后再发送。

若要突出位保持，可在`led 37`之后逐条发送“只关闭LED0，其他LED保持不变。”和“单独点亮LED0，其余LED保持原状。”，拍到掩码37→36→37与实物变化。先关闭LED0、再读取温度应分成两条发送；一句多动作请求按当前规则拒绝。
