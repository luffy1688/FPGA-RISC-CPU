# 澄灯 LumaRV 拍摄配音与剪辑脚本

成片按2分45秒设计，重点展示一项任务：工程师在后台计算期间临时复测控制板。技术报告解释设计与测量方法，视频呈现实际操作，PPT用于答辩补充。

## 开拍前

把板卡、电源、串口USB和JTAG放在同一画面内。报告与视频不出现姓名、学校或导师信息。关闭其他串口程序，在Edge打开：

http://127.0.0.1:8765/?present=1&baud=921600&arch=1

选择CP210x串口和921600波特率，连接成功后短按KEY0，等54MHz、双核与“就绪”。当前电脑的UART为COM10，FTDI COM13/14用于JTAG。串口打开失败时，先关闭占用它的程序；按KEY0不能释放电脑端口。拍摄时每次等“就绪”再发下一句。

先完整录一份原片，保留开始、返回和实物变化，后期从原片取镜头。表中时间是成片长度，不是程序运行时间。

## 实际操作顺序

1. 连接后等“就绪”，点“快速控制”，准备完成后发`led 0`作为初始状态。这段可不放入成片。
2. 点“后台计算自检”，看到副核忙碌后，立即点“一键AI识别·PWM20%”。按钮负责确认模式，再发送中文请求。
3. 拍清本次完整模型时间、PWM20%及周期54000/高电平10800；后台状态若已完成，保留完成结果，不重造忙碌画面。
4. 点“快速控制”，等确认完成后，逐条发送`led 37`、`只关闭LED0，其他LED保持不变。`。掩码应为37→36；如补拍置位，再发`单独点亮LED0，其余LED保持原状。`，回到37。
5. 发送`把PWM频率改成2kHz。`，保留拒绝结果和PWM设置。这里使用快速控制的默认混合路径；不要在此段切到强制完整模型。
6. 副核空闲后点“CPU自检”，等待两核CRC、共同时间和“就绪”；再下载本次日志。

录制最简版只需要“一键AI识别·PWM20%”和“快速控制后led 37”两段。完整成片再加入后台并行、LED位保持、拒绝和CPU自检。

## 字幕与配音

`展示素材/拍摄剪辑模板_字幕.srt`与本表的2分45秒分镜对应。将原片、3D MP4和SRT导入剪辑软件，再按表中台词录音。数字读到能听清即可：54.640毫秒读作“约五十四点六四毫秒”；4.038437读作“约四点零三八每兆赫”，画面保留完整数值。

3D的20秒成片已经按3倍速制作，直接插入，不再加速。操作等待若加速，画面标“3×”；请求、回读、拒绝和CRC特写正常播放2～3秒。CoreMark计时始终采用板卡返回值，不用剪辑长度代替。保留一段连续的板卡与屏幕同框画面，让LED变化和页面回读对应起来。

配音与字幕都围绕本镜头在做什么，不反复朗读“证据、审计、真实、冻结”等说明。3D画面角落保留“逻辑结构示意”，UART结果处保留处理路径、请求值、读回和计时。

## 团队项目介绍口播

我们从RISC-V处理器设计出发，做了一套控制板复测系统。它能理解中文中的操作和限制，比如只关闭一个LED，同时保留其他状态。我们完成了语境模型、低比特加速器和双核控制系统，让后台计算与临时调参可以并行，操作后再检查寄存器读回。这次演示用开发板展示从输入到执行的完整过程。

此段用于向老师或评委介绍项目，约35～40秒。正式匿名视频采用上表的短开场，不出现团队身份资料。
