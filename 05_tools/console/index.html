从一句话到外设：每一层做什么？

① UART 输入

USB-UART 把 UTF-8 字节送给 FPGA。CPU 读寄存器并整理为一行文本。

② 轻量语义模型

显式schema命中时跳过模型；未命中才计算6类分数。原创Needle-inspired窄域模型可能误判，实际执行仍受合同检查。

③ CPU 与 XND

CPU 执行程序并提交 GEMV；XND 并行计算 INT4 × INT8。输入槽驻留能减少重复搬运。

④ 参数校验

CPU 检查工具与数值边界。例如 PWM 必须是 0～100；模型不能直接写任意外设地址。

⑤ 工具与回报

通过校验后控制 LED、PWM 或查询计数器。片内 ADC 尚无有效温度样本时返回“暂不可用”。

驻留数据统计目前是片上 RAM 的 DMA 字节，不能解释成外部 DDR 流量；引擎周期不是 CPU 总周期；权重预取重叠的收益需按当前硬件实测分别说明。
