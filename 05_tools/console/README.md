# LumaRV 串口控制台

控制台通过Web Serial连接开发板，提供中文请求、快速控制、双核自检、寄存器读回及三维结构展示。

## 启动

在工程根目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory 05_tools/console
```

Edge或Chrome打开 http://127.0.0.1:8765/?present=1&baud=921600&arch=1 ，选择CP210x UART和921600波特率。连接成功后短按KEY0，等待启动信息、54MHz与“就绪”。当前电脑UART为COM10，FTDI COM13/14用于JTAG。端口被占用时，先关闭其他串口程序。

## 常用入口

|入口|操作|
|---|---|
|一键AI识别·PWM20%|逐项确认完整模型、配置6和完整输出后，发送中文PWM请求|
|快速控制|确认默认混合路径及紧凑输出，再填入led 37；点击发送执行|
|后台计算自检|启动私有存储中的副核，主核继续处理中文请求与外设|
|CPU自检|运行两个独立CoreMark实例，显示各核CRC、计时和累计吞吐|
|三维结构|旋转、分层，查看一次请求经过的处理模块|

单条请求最多64个UTF-8字节。发送后等待结果与新的NR_READY。第四版25句下拉菜单只填入文字。LED位保持推荐在“快速控制”模式下执行；强制完整模型对个别合法表达仍会误拒绝。

## 结果与计时

页面显示执行工具、请求值与寄存器读回、模型参与情况、完整模型时间和工具时间。详细配置、PMU和原始分数在折叠区。0～6配置用于软件与计算策略对照，普通演示使用配置6。

完整模型与语境分支分别标记；整数分数和分差用于分类及门控。写后读回核对LED最终掩码、PWM周期/高电平计数及使能。浏览器TX到结果或READY的时间包含USB、串口与浏览器调度。

54MHz实板指定中文PWM完整模型54.640ms；四句各10次的原生UART往返中位数为1.32～3.66ms。CoreMark每核3000次，主核中位数4.038437/MHz；双实例共同14.280421秒，累计7.780660/MHz。

## 请求处理和记录

同一时刻只处理一条工具请求或模式切换，收到匹配确认后再推进。错误确认、缺结果、重启或断连时停止后续发送。LED/PWM需要同时核对请求和读回字段。日志保留输入、串口原文、配置、处理结果和计时，可导出文本及JSON；清空显示不会删除已接收记录。

三维画面表示逻辑结构，显示高亮可由本次返回驱动；旋转、展开与讲解不发送外设命令。

