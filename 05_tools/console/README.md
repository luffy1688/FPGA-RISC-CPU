# NeedleRV-X 板卡自检与现场运维控制台

更新：2026-10-31。当前冻结固件`experimental_position_fusion_oct30`、协议6、40.5MHz、UART921600/8N1。页面修改不改变固件、模型或实板成绩。

## 评委演示入口

默认演示URL：`http://127.0.0.1:8765/?present=1&baud=921600&arch=1`。连接后取得本次BUILD/READY，主界面显示当前已确认模式；工程下拉仅是待选值，未应用会提示，不能当成实际模式。上次结果另外保留该次请求的模式，发送新工具请求时先清空旧成绩。

- **一键AI识别 · PWM20%**：实际发送`:fast 0`，收到匹配ACK和READY后发送`:config 6`，再次确认后发送`:format full`，最后发送`请将PWM占空比设置为20%。`。不自动猜测当前设置。结果必须实际使用完整模型、工具为PWM、参数20且回读通过，否则停止并保留拒绝/失败。
- **快速控制**：实际确认fast1、config6和compact，只把`led 37`填入输入框；用户再发送。该模式成功显示绿色“实板已执行 · 快速控制”，AI未使用作为路径事实保留。
- **CPU自检**：确认快速模式后发送`运行CoreMark并显示CRC结果。`，等待实际CRC、计时、工具成功及READY。无需模型不是错误，CoreMark成绩仍来自真实计时。

切换链路占用唯一请求通道，期间不接受其他手动发送、模式切换或健康检查。控制超时15秒、工具超时60秒后停止，不自动重发；超时不取消板上已经开始的动作。任何错ACK、缺结果、拒绝、回读失败、重启、断连都不报告完成。当前245项假DOM/串口检查包括这些路径，不冒称新一轮实板或Edge验收。

主结果保留动作/回值、寄存器回读、AI实际使用、完整模型耗时与工具时间；7配置、路径/输出选项、PMU与原始分数折叠在工程证据中。折叠只改变显示，原始审计导出不删减。

## 连接与单条请求

在第二屏Edge/Chrome以localhost或HTTPS打开`index.html?present=1&baud=921600&arch=1`。页面默认921600，115200只用于明确选择的历史恢复固件。默认设备选择仅列出CP210x UART（VID10C4/PID EA60，对应当前COM10），FTDI COM13/14是JTAG，不可当作UART。工程选项中的“其他USB-UART”是单独高级入口，已知FTDI双通道JTAG仍禁止误选。串口成功打开后才按KEY0取得本次NR_BUILD和NR_READY；端口打开失败应先处理正确设备或占用，KEY0不能释放主机端口。端口打开不代表固件已启动；缺少有效构建身份或频率时，READY也不开放发送。

每条输入最多64 UTF-8字节。第四版25句和预设只填入文本；发送后等待实际结果和新的READY，不自动重试。电脑负责收发、显示和顺序汇总，语义计算与工具执行都在板上。页面不读取网络模型。

`model_used=0`表示模型未运行；2/3表示只运行语境头，不能补出六类编码器分数；1为完整神经路径。原始神经分类、规则选择和实际工具分别呈现。整数logits和margin不是概率。显式机器语法可以跳过模型，中文自然语言按固件实际分链路处理，不能把规则或系统成功计为神经正确。

## 审计与回执

日志面板的逐条审计表显示最近12条请求。JSON最多保留256条请求，并在截断时标记。每条包含原始命令、启动段、已确认配置、完整返回结果、回读核对、控制确认、发送/结果/READY时点和完成状态。浏览器采用单调时钟计算耗时，日期时间只用于定位记录。

文本协议按单请求串行顺序及报告配置关联，**不是设备级请求序号认证**。协议6下错误配置、重复结果和错误响应类型不能替换已接收的本次结果；控制回执必须与请求值一致。只有READY而没有当前回复不算请求完成。损坏BUILD也会清除旧身份、能力、频率与配置；正在执行的请求保留“设备重启中断”，旧结果和成绩清空。

LED写入要求回读类型、预期最终掩码、实际回读和value一致。PWM另外检查周期、高电平计数、使能、请求占空比，以及1kHz周期关系。match=1单独不足以确认成功。温度和计数器是只读采样，不能描述为写入ACK；寄存器匹配不代表外部引脚或负载测量。

原始UART行、无法解析的记录和RX字节仍保留。日志和证据约2MB容量上限，截断会声明。清空日志显示不删除证据；新连接会创建新会话，先前证据应先下载。页面不把静态预设、结构讲解或历史离线结果写成当前Web Serial实测。

## 时间和软硬件比较

浏览器TX至完整结果/READY包含UART、USB、浏览器调度和工具运行，不等于原生链路基准，也不等于纯FPGA计算时间。完整神经时间、语境子区间、编码器时间、决策时间和工具时间分别显示，缺字段则不补造。

同一句config0/6只接受同会话同启动段、实际运行完整模型、全部已报告分数字段和工具合同一致的完整结果。除六类与编码器原判，还核对语境类别、语境工具、修复、级联和身份残差；任一不一致都不形成加速结论。快路径不能参与模型加速比。重启清空显示对照，原始收发仍在证据中。

CoreMark分数按`iterations*1e6/cycles`计算；当前1200迭代样本应约2.031490/MHz，不能显示旧固件6位定点整数。必须有算法validated、无错误、成功返回以及至少10秒精确计时，才显示本次成绩。PMU采样周期不替代基准计时，也不据此声称官方认证。

冻结实板四个显式句子各n10的原生往返中位数1.40～5.16ms，完整PWM模型74.567ms、其中语义区间0.837ms。它们是不同口径，页面不把0.837ms写成完整推理时间。

## 健康检查与三维展示

健康检查按单工具请求串行推进，必须收到匹配结果和真实READY。包含IO写入时先保存初值，仅在PWM可精确恢复时测试该项；错误、重启或断连立即停止后续发送，报告保留手动恢复值，不擅自补发恢复动作。

三维场景是结构与数据流示意，不是物理布图或逐拍遥测。真实返回高亮和结构讲解分开，讲解、旋转、展开、全屏不会发送串口指令。缺构建身份的结果不继承冻结版本能力。独立只读讲解与实测记录回放由单独展示页承载，不覆盖当前串口会话。

## 必要验证

服务器运行`node test_console.cjs`。该测试用隔离假DOM/串口和原始冻结实测帧验证页面逻辑；不得冒称真实Edge、本版连续录屏或外屏验收。最新行为结果由`behavior_report.json`记录，开发过程不占用COM10。

## 本机原生桥验收脚本

`verify_demo_native.cjs`将生产页面JS状态机接到原生Win32 UART字节流；DOM和Web Serial外壳为隔离适配，不是Edge窗口或外屏验收。仅在用户已断开浏览器、明确移交端口后运行。默认等本次KEY0启动；`--bootstrap-json`与`--assume-ready`必须成对使用，代表明确READY移交，引用先前启动身份而不伪造本次RX。脚本自动核对AI PWM、快速模式/LED和CPU自检12项事务，失败/超时停止，不重试或烧录，原始结果文件不覆盖。`--check-only`仅检查嵌套脚本语法，不开串口。
