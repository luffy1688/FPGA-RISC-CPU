# 中文语境与工具模型

模型面向五类板卡工具及拒绝请求，输出语境和工具分数。参数解析、能力许可与执行由固件完成。

## 模型结构

|部分|结构与计算|
|---|---|
|字节编码器|两层d64、四注意力头、学习型2/3-gram短语记忆；4MAC|
|位置语义分支|全局1024维、句首句尾各512维；2048→64→16；8MAC|
|工具残差|64维隐层加六类编码器分数，70→5；CPU标量|
|数值|INT4/INT8权重、INT32累加；学习权重197816B|
|数据复用|128KiB第一层权重缓存、全零特征组跳过|

设计参考Needle的低比特工具调用和字符短语记忆。中文任务数据、位置分支、受约束残差、整数运行时和板卡计算接口由本项目实现。

## 训练数据

训练文本共25014条：合法操作9155条，拒绝及非执行表达15859条。合法操作包含温度1457、PWM2488、CoreMark1104、计数器1460、LED2646条。数据由任务样本、合成语境扩展及2800条按本板能力重新标注的MASSIVE中文域外请求组成。

四批用户指令用于回归。1138条与900条难例用于开发比较；两组神经分类结果为1087/1138和685/900，混合系统结果为1135/1138和884/900。模型分类、许可后的工具参数判断、Python/C数值一致性分别评价。

## 目录与部署

`datasets`、`train`、`export`和`golden`保留编码器基础数据、训练导出与整数参考；后续位置语义及候选比较位于`needle_candidate_pipeline`。部分早期候选目录用于复现实验，不作为当前固件入口。

板卡实际使用的整数参数在`03_sw/model/byte_model_data.h`、`byte_engram_data.h`、`byte_context_data.h`和`byte_semantic_data.h`，推理实现位于同目录的C文件和包含文件。构建双核应用使用工程根目录的`05_tools/build_dual_firmware.py 3000 54000000`。仅运行早期编码器训练脚本不会生成完整部署模型。

更多训练和部署输入位于`07_runs/development`。模型在服务器训练和导出，参数编入主核固件；副核不复制模型。指定中文PWM请求的完整模型在54MHz实板为54.640ms，同镜像软件路径658.079ms。

数据与依赖的来源及许可见工程根目录`第三方来源.md`和`09_refs`。合成语料的生成信息、首次评价与失败样本保留在各自原始数据和结果中。
